Panduan Penggunaan

1. Klik menu di sidebar kiri untuk mengedit section yang diinginkan.
2. Untuk gambar, masukkan URL gambar atau upload file (gambar akan disimpan sebagai Data URL).
3. Untuk video, masukkan URL embed YouTube/Vimeo (format: https://www.youtube.com/embed/ID).
4. Klik Simpan & Terapkan di kanan atas — perubahan langsung aktif di website.
5. Klik Lihat Website untuk melihat hasilnya.

Catatan: Data disimpan di browser (localStorage). Untuk backup, gunakan fitur Export di bawah.
