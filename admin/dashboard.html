Panduan Penggunaan

1. Klik menu di sidebar kiri untuk mengedit section yang diinginkan.
2. Untuk gambar, Anda bisa memasukkan link URL gambar atau upload langsung (gambar akan dioptimalkan otomatis).
3. Untuk video, masukkan link YouTube biasa atau embed (misal: https://www.youtube.com/watch?v=...).
4. Klik Simpan & Terapkan di pojok kanan atas — perubahan langsung aktif secara instan di website!
5. Klik Lihat Website untuk melihat hasil perubahannya.

Cadangan Data: Gunakan tombol Export di bawah untuk backup data CMS Anda.
